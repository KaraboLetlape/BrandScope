# BrandScope Changelog

## Version 3.0 — Part 3
- Added dynamic, case-insensitive product search and live result count.
- Connected the header search icon to the product search field.
- Added an enquiry bag with add/remove controls, live item count and WhatsApp enquiry link.
- Added an accessible image lightbox for category and product images.
- Added keyboard support for Escape and arrow-key gallery navigation.
- Added an interactive Johannesburg map to the Contact section.
- Added page-specific SEO titles, descriptions, keywords, author, robots and Open Graph metadata.
- Renamed image assets with descriptive lowercase hyphenated filenames.
- Added meaningful alt text and lazy loading to content images.
- Rebuilt featured product images as semantic image elements.
- Expanded the contact form with enquiry type and optional phone number.
- Added client-side validation, inline field errors and accessible live feedback.
- Changed the form success flow to prepare an email via the visitor's email application rather than falsely claiming server-side delivery.
- Updated README with feature descriptions, test checklist, GitHub commit guidance, deployment steps and references.

## Version 2.0 — Part 2
- Added external CSS stylesheet, responsive layout, grid/flexbox styling and responsive image variants.
- Improved navigation, product pages, typography and responsive breakpoints.
- Added hover, focus and active states.
- Documented Part 2 implementation and testing guidance.

## Version 1.0 — Part 1
- Initial BrandScope website structure, homepage, category content and product detail pages.
