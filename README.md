## 1. Project Overview

BrandScope is a streetwear-focused website created to present and showcase curated fashion products and brands. The website is designed around streetwear culture and provides visitors with an organised way to browse featured products and view individual product information.

The website foundation was developed using HTML, CSS, images and JavaScript folders. The project includes a homepage and individual product pages, with navigation links used to connect the website content.

---

## 2. Website Goals and Objectives

The main goals of BrandScope are to:

- Create a modern website focused on streetwear culture.
- Present selected clothing products in an organised format.
- Allow users to navigate between the homepage and product pages.
- Provide product information such as brand, size, condition and price.
- Create a clear and easy-to-use website structure.
- Establish a foundation that can be expanded in future parts of the project.

---

## 3. Target Audience

BrandScope is aimed at people interested in streetwear, fashion, branded clothing and curated clothing collections.

The website is intended to provide a simple browsing experience where visitors can explore products and learn more about individual items.

---

## 4. Key Features and Functionality

The current Part 1 website includes:

- Homepage with BrandScope introduction.
- Main navigation menu.
- Shop-by-category section.
- Featured products section.
- Individual product pages.
- Product information including brand, size, condition and price.
- Links from product listings to individual product pages.
- CSS styling for the website presentation.
- Image assets organised in an images folder.
- JavaScript folder for project functionality and future development.
